# MotionForge AI｜AI 自动生成 MG 动画视频

**给一条参考视频、一份新文案，让 AI 拆解镜头、复现快闪动效、重做主题画面，输出 MG 动画视频。**

Reference video + your script → motion graphics, kinetic typography & a finished MP4.

不用先做表格，不用自己标时间码，也不用逐镜写动画提示词。支持整片制作，也支持“只参考前 20 秒，文案按顺序能放多少放多少”。

这是供具备视频/图片查看与代码执行能力的 AI 使用的 **Skill 工作流**。AI 负责分析与制作，辅助脚本负责抽帧、合成、渲染和检查；需要可执行的视频处理环境。GitHub 仓库本身不是在线视频生成网站。

## 直接使用

1. 点击本页 **Code → Download ZIP**，解压；也可以克隆仓库。
2. 将 `skills/remake-reference-video` 整个文件夹安装到你的 AI 工具支持的 Skills 目录。
3. 上传参考视频，粘贴新文案，例如：

```text
使用 MotionForge AI（remake-reference-video）。
参考附件视频的前20秒，把下面的文案做成MG动画。
保留参考的文字动效、镜头运动、动画元素、转场和风格；
画面按新文案重新制作，文案按顺序能放多少放多少。
输出20秒、9:16、无声视频。

新文案：
灵感即刻出发
让每个想法动起来
把创意变成看得见的作品
```

也可以只说“参考这个视频，按下面的文案制作 MG 动画”。未指定时长时使用整条参考片，无需每次重复完整要求。

**只想替换文字：**说“只替换中英文，其他画面和动效保留”，会使用精确换字流程。文案可以是整段、分行短句、中英文对照，或“原文 → 新文”。

展示名称已升级为 MotionForge AI；内部调用名和安装路径继续使用 `remake-reference-video`，兼容已有安装。也可让能读取文件并执行代码的 AI 直接读取 [SKILL.md](skills/remake-reference-video/SKILL.md)。

## 这次升级解决什么

| 容易出错的地方 | 对应改进 |
| --- | --- |
| 只替换文字，漏掉画面动画 | 文字、镜头、场景、装饰、转场五类动效逐镜拆解、实现和验收 |
| 要前 20 秒却用了整片 | 按帧限定参考窗口，保留请求范围和实际起止帧 |
| 为塞完全文破坏节奏 | 用户允许部分使用时取可完整表达的连续前段，记录剩余文案 |
| 新文案配的仍是旧主题画面 | 按新稿重做信息载体和场景，保留参考动作机制与节拍 |
| 只凭时长和尺寸正确就交付 | 将镜头清单关联真实图层、素材和底片，另做逐镜视觉验收 |

场景素材生成、动画制作和合成由 AI 调用实际可用工具完成。脚本检查通过，不等于视觉复刻已经验收。

## 默认设置

| 项目 | 默认处理 |
| --- | --- |
| 视频 | 1080 × 1920、9:16、H.264 MP4 |
| 声音 | 不含音轨 |
| 时长与帧率 | 延用所选参考范围；本次明确要求优先 |
| 视觉 | 采用本次参考的配色、构图、动画与节奏 |
| 文案 | 自动分段、匹配槽位，核对中英文、数字、单位和标点 |
| 字体 | 用户提供的授权字体优先；否则自动获取 Noto Sans CJK SC Bold |
| AE | 有真实可运行环境时优先原生制作；否则使用可执行合成工具输出 MP4 |

## 运行环境与字体

需要 Python 3.11+、FFmpeg/ffprobe，以及 Python 依赖：

```bash
python3 -m pip install -r requirements.txt
ffmpeg -version
ffprobe -version
python3 skills/remake-reference-video/scripts/font_setup.py
```

公开版默认字体采用 **SIL Open Font License 1.1** 授权的 Noto，首次使用从固定官方版本下载并校验，后续复用缓存。许可与来源见 `assets/fonts/`。离线环境请预先准备缓存或提供自己的单字体 TTF/OTF。

公开仓库不包含私人使用的三极字体；希望使用该字形时，使用者需提供自己有权使用的字体。公开默认字形与三极不同。

## 能力与验收边界

只有 MP4 时，无法直接还原被压平的隐藏图层、原作者工程或未知插件。精确换字采用底片修复与文字重建；场景重制需要 AI 实际制作合成、素材和预渲染画面。包内基础渲染器支持文字变换与帧序列合成，**不自带通用三维动画生成器**。

透视、穿行、翻页、遮挡等复杂效果，需通过可用 AE、其他合成代码或预渲染实现，不能只用静态图加缩放冒充完成。生成式工具可用于合适的场景素材；具体模型依赖使用者实际接入的能力。精确文字、时间轴与最终转场由可控合成处理。

自动检查覆盖真实短片渲染与解码、字体、文字完整性、参考窗口和镜头清单。它们用于发现结构错误，完整视觉复刻仍须逐镜验收。不承诺任意参考片逐像素一致，也不把仅生成 JSX 当作 AE 已渲染。

## 主要文件

- [SKILL.md](skills/remake-reference-video/SKILL.md)：制作模式、执行与交付规则。
- [motion-remake.md](skills/remake-reference-video/references/motion-remake.md)：镜头拆解、场景重建与视觉验收。
- [shot-contract.md](skills/remake-reference-video/references/shot-contract.md)：镜头、文案和动效清单格式。
- `scripts/video_pipeline.py`：限定范围抽帧、遮罩、底片清理、文字渲染与验证。
- `scripts/motion_contract.py`：检查镜头、所选文案和实际素材的对应关系。
- `scripts/export_ae.py`：导出 AE 原生文字层与关键帧构建脚本。
- `tests/`：可复现的渲染与错误输入检查。

只运行脚本不会自动理解视频；请让 AI 按 Skill 分析并制作。觉得有帮助，可以在右上角点 **Star** 收藏，也欢迎通过 Issues 反馈具体镜头和问题。
