# 参考视频自动换稿

**提供参考视频＋替换文案，让 AI 自动匹配时间轴、重建文字动效，输出竖版无声视频。**

无需填表、标时间码或逐镜提示。适合文字快闪、MG 动画、宣传片换稿，以及只有 MP4、没有 AE 源工程的改字任务。

这是给具备视频/图片查看与代码执行能力的 AI 使用的 Skill。AI 负责理解文案、分析画面和制作动画计划；辅助脚本负责抽帧、合成、渲染与技术验证。GitHub 仓库本身不是视频生成网页。

## 直接使用

1. 点击本页面 **Code → Download ZIP**，解压；也可以克隆仓库。
2. 将 `skills/remake-reference-video` 整个文件夹安装到你的 AI 工具支持的 Skills 目录。保留其中的 scripts、references 和 assets。
3. 给 AI 上传参考视频，粘贴新文案。例如：

```text
使用 remake-reference-video，把附件视频换成下面的文案：
看病别慌
一路陪你
有需求，快响应！
英文统一为 HEALTH CARE
```

也可以让能读取文件和执行代码的 AI 直接读取 `skills/remake-reference-video/SKILL.md` 并执行。文案可以是整段、分行短句、中英文对照，或“原文 → 新文”。

## 默认效果

| 项目 | 默认处理 |
| --- | --- |
| 视频 | 1080 × 1920、9:16、H.264 MP4 |
| 声音 | 不含音轨 |
| 节奏 | 沿用参考片的时长、帧率、镜头顺序与快闪节奏 |
| 背景 | 尽可能保留原底片、圆环、线框、粒子和空屏 |
| 文案 | 中文、英文及重复文字层对应替换；核对数字、单位、标点 |
| 英文 | 已提供则采用；仅给中文且原片有英文时自动配简短英文 |
| 字体 | 用户提供的授权字体优先；否则首次使用自动下载 Noto Sans CJK SC Bold |
| AE | 有可运行的 AE 和源工程时优先原生替换；否则先交逐帧合成 MP4，可附 AE 文字层构建脚本 |

本次明确要求会覆盖默认，例如保留音效、更换字体或指定画幅。

## 运行环境

需要 Python 3.11+、FFmpeg/ffprobe，以及：

```bash
python3 -m pip install -r requirements.txt
ffmpeg -version
ffprobe -version
```

首次使用默认字体需要访问官方 GitHub 字体下载地址。脚本使用固定版本、校验文件大小及内容摘要，下载后缓存复用。也可预先运行：

```bash
python3 skills/remake-reference-video/scripts/font_setup.py
```

无网络环境可以预先准备默认字体缓存，或提供自己的单字体 TTF/OTF。

## 字体说明

公开版默认采用有 **SIL Open Font License 1.1** 授权的 Noto 字体，完整许可和来源说明位于 assets/fonts。此前个人版本使用的“三极行楷简体-粗”未包含在此仓库中，因此默认字形不同。

希望使用相同字形时，提供你有权使用的三极字体；也可选用其他授权字体。AI 会优先采用并检查缺字。脚本从字体文件读取真实 PostScript 名，避免 AE 字体名称配置错误。

## 制作流程

1. 抽帧识别全部中英文、文字变化与转场。
2. 理解新稿并匹配原文字组，处理重复镜头与英文位置。
3. 清除旧字、英文与残影，检查无字底片，保护装饰元素。
4. 重建缩放、旋转、逐字入场、滚动和叠影，适配新字数。
5. 检查全稿、稳定阅读段、转场前后帧和技术规格，交付 MP4。

映射、遮罩、动画计划与检查记录由 AI 管理，用户无需填写。

## 质量边界

最适合背景可分离、文字清晰的 MG 快闪。只有成片时，采用“原片底片保留＋文字动效重建”；无法从 MP4 恢复隐藏图层或未知插件，也不承诺任意参考片逐像素一致。复杂实拍遮挡、重度模糊和三维文字需要逐镜评估。

工作流此前通过独立执行测试，凭参考片和自然语言新稿完成分段、中文替换、统一英文及 1080 × 1920 无声输出。公开版本另设自动检查，覆盖默认字体、文案完整性、实际短片渲染、全片解码及 AE 脚本导出。画面修复和运动一致性仍须 AI 查看实际画面确认。

仅生成 JSX 不代表 AE 已运行。未实际执行 AE 的任务须明确说明，以可播放的 MP4 为主交付。

## 文件说明

- `skills/remake-reference-video/SKILL.md`：完整执行规则。
- `references/`：帧级制作方法与动画计划格式。
- `scripts/video_pipeline.py`：抽帧、遮罩、底片清理、渲染和验证。
- `scripts/export_ae.py`：生成 AE 原生文字层与关键帧构建脚本。
- `scripts/font_setup.py`：下载并验证默认字体。
- `assets/fonts/`：字体来源与许可说明。
- `tests/smoke.py`：可复现的渲染和导出检查。

只运行渲染脚本不会自动理解整条视频；请让 AI 先按 SKILL.md 分析参考片并制作计划。
