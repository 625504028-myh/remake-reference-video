# 保留原动效与画面

本文件沿用旧文件名以兼容已有引用；当前规则只有**原视觉保留与文字替换**。此前“按新语义生成场景”“更换道具或动画机制”的制作模式已停用，不得从旧文件名或历史任务恢复该行为。

## 五项独立保留检查

先完整拆解参考，再为实际输出范围记录以下五类内容。不存在的项目明确记为无，不能遗漏存在的效果。

| 类别 | 必须保留的内容 |
|---|---|
| 文字动画 | 主次层级、逐字错峰、路径、透视、翻转、弹性、叠影、纹理、遮挡、入场与退场节拍 |
| 镜头运动 | 推近/拉远、平移、旋转、穿行、焦距感、透视消失点及停顿 |
| 场景动画 | 原主体、道具、界面、物体动作、运动路径和层间遮挡 |
| 装饰元素 | 线框、光条、粒子、圆环、几何形状的样式、数量、位置及运动 |
| 转场 | 硬切、闪白/闪黑、遮挡、翻页、穿屏、动作匹配与相邻帧关系 |

仅文字的内容允许按授权替换。根据新字数适配逐字错峰、排版时，保持同一运动机制和时段，不把复杂透视、翻转、穿行等简化为普通缩放或交叉淡化。不能以“风格相近”代替原效果保留。

## 不因脚本换题而改变原场景

原片里的手机、装置、建筑、人物、道具或动画主体保持原样。新稿与旧画面主题不同也不能自动生成新场景、替换主体、重画界面非文字内容或增加创意镜头。当前Skill执行的是换字；若用户另行要求画面重做，明确视为超出本流程的新范围，不能悄悄执行旧模式。

原几何装饰、粒子、光影、材质和镜头运动优先通过保留源像素实现。去字过程中只修复确实被旧文字覆盖的区域；使用相邻帧、跟踪与可验证几何恢复原背景，不用文生图/文生视频编造被遮住的场景。无法从压平视频恢复的区域须说明具体限制，不宣称已找回隐藏源图层。

## 文字绑定与遮挡

每个改动语言分别绑定其主层、阴影、倒影、描边、模糊拖尾及转场残片。只改中文时英文不动；明确删除某语言时清除它的全部附属文字效果，但保留非文字装饰。

文字与场景有遮挡关系时保留该关系。原本固定水平的英文不能误跟随中文旋转；屏内文字应沿原屏幕透视与运动合成；逐字弧线、前后景穿插、翻页文字不得改成静止覆盖。新字数造成不可读或溢出时先做保持层级的合理分行，无法解决则报告容量/字体冲突，不改变原镜头速度。

## 片段边界的动效依赖

文字效果的起止不等于最后一次OCR读到文字的时刻。结合逐帧回看标记完整入场起点、退场末帧、模糊拖尾和必要共享转场；源范围采用左闭右开区间。

A只导出改动片段，可根据实际证据包含最小必要过渡依赖；不连续范围分别输出，不新增拼接转场。B保留从第0帧到最后已用槽位效果结束的原片前缀，不添加下一旧标题或无用尾段。过渡依赖与排除无关内容相冲突时说明具体位置，不能静默删效果、改场景或扩大到整片。

## 使用真实可执行的能力

- 可编辑源工程可用时，替换原文字层内容，保持关键帧、表达式、摄像机、灯光、遮罩、效果和音轨。
- 只有参考视频时，以源底片保留、局部去字和文字重建为路径。必要时用跟踪、透视合成或可用AE实现原文字运动，不创建新的场景动画。
- 未知插件、缺失字体或复杂遮挡无法准确恢复时，明确对应镜头与差异。优先解决可解决的问题，但不能因工具限制省略动效后声称完全复刻。
- 仅导出JSX、写出提示词或完成结构校验，都不等于实际视频制作、AE执行或视觉验收完成。

## 三步视觉验收

1. **无字底片对照**：只检查需要替换文字的区域是否已清理，未改语言与全部非文字场景、元素、动作仍保持；无补丁、断线或误清。
2. **文字效果对照**：检查每个新文字层的入场、阅读、退场、影层、透视、遮挡与原节拍，核对完整新稿和逐语言授权范围。
3. **最终片段连续对照**：完整播放每个输出文件，对照原时间段核对五项保留内容、边界、声音同步、尺寸和帧率。

视觉完整保留是目标，检查记录必须来自实际产物；不能把“计划保留”写成“已完全一致”。
