# 参考模板的镜头重建

## 先拆运动，再换内容

将所选参考片段划分为完整镜头和镜头内部的动作阶段。镜头边界来自切点、遮挡或动作衔接，不按固定秒数平均分段。为每个镜头记录源帧区间、输出帧区间、阅读槽位，以及五类可独立验收的运动：

| 类别 | 必须观察的内容 |
|---|---|
| 文字 | 主次层级、逐字错峰、弧线/路径、透视、翻转、弹性、叠影、纹理、进出场 |
| 镜头 | 推近/拉远、平移、旋转、穿行、焦距感、透视消失点、节奏及停顿 |
| 场景 | 主体动作、道具运动、界面滚动、物体翻面、运动路径、层间遮挡 |
| 装饰 | 线框、光条、粒子、圆环、几何形状的数量、位置、出现时间和运动 |
| 转场 | 硬切、闪白/闪黑、遮挡切、翻页、穿屏、动作匹配、末帧与下镜头首帧关系 |

没有某项时记为无。不要把“快闪”“高级”“参考风格”三个泛词当成镜头计划。记录可观察的方向、相位、层级、关键帧和动作落点；复杂段检查逐帧序列与连续播放两种证据。

## 有边界地替换场景语义

新脚本决定“展示什么”，参考决定“怎么动、何时动、如何衔接”。优先保留动画机制，更换承载新信息的主体、内容和道具。例子仅说明映射方法，不是每个任务必须出现的模板：

- 参考是透视手机滑屏：把界面内容换成新主题，保留手机角度、屏内滚动、遮挡和镜头移动；不要仅在平面截图上加字。
- 参考是层层穿行：按脚本重做层叠物体，保留纵深、速度变化、经过镜头的先后和消失点；不要改成普通交叉淡化。
- 参考是翻页：新页内容随脚本变化，保留翻折方向、厚度感、遮挡、光影与落页节拍。
- 参考是装置动作后拉远：替换为能表达新内容的主体与动作载体，保留启动、动作结果、拉远揭示和后续硬切的阶段关系。若用户明确要求原装置不变，则只替换其内容。

仅当用户允许创新或要求换掉某动画时，改变该镜头的动画机制；仍对齐其时长、视觉密度、整体风格和上下镜头接续。不擅自把全片重设计为另一种节奏。

## 固定时长内选择文案

建立按原顺序排列的语义单元，数字、单位、比较条件与限定语不可随意拆开。先估算每个文字槽位的稳定阅读段，再用实际预览校正；不要用单一“每秒几个字”的公式替代可读性检查。

允许部分使用时，选择能在目标时长内完整呈现的连续前段。可以用完整子句结束，但不能截断数字关系、条件或因果结论。除非用户明确允许，不跳过前文择取后面的亮点，不擅自改写数据。记录每个已用单元对应的镜头；记录未使用的剩余文案，便于用户知道使用范围。

镜头空白、蓄力停顿或无字动作是节奏的一部分，不等同于可以随意填充的字幕槽位。结束点已固定时，不增加尾卡、拖长最后一帧或挤压所有镜头来塞完文案。未授权部分使用而全文与时长冲突时，说明具体冲突后再作必要取舍。

## 选择可执行的制作路径

- **可编辑源工程可用**：在原生层替换内容，保留表达式、关键帧、摄像机、灯光、遮罩和效果；验证字体、素材、插件均可用。
- **只有参考视频**：用2D/2.5D/3D合成重建实际可见的运动；新场景先输出无字预渲染，再加入可控文字与转场。不能假设能从压平视频恢复源图层。
- **需要生成场景素材**：按镜头明确主体、动作阶段、构图、运动方向、相机路径、色彩、光照、时长及首尾衔接。验证拿到的是实际可解码产物。精确汉字、数字、英文与品牌标志留在合成阶段。
- **工具未支持某效果**：先尝试可行的预渲染、脚本扩展或已连接的专用能力。不能用“已有工具只能做文字”作为删去场景动作的默认理由；确实无法实现时说明对应镜头的具体限制。

把镜头清单、实现路径与实际计划关联，格式和检查命令见 `shot-contract.md`。仅写了提示词、素材仍在生成、没有可用输出或未观看产物，都属于未完成。结构检查不能证明视觉一致。

## 三轮检查完成一个制作闭环

1. **无字场景检查**：对照参考核对镜头、场景、装饰、转场，避免叠字掩盖缺失动画。检查新场景是否准确表达脚本。
2. **文字合成检查**：加入所有语言、影层和转场文字，核对入场、稳定阅读、出场及遮挡。新增字数不能破坏原节拍。
3. **全片连续检查**：对照所选参考完整播放成片，逐镜检查五类动效并记录通过证据。用实际帧数确认时长，校验音轨和输出尺寸。

修复已发现的问题并复查关联镜头。禁止把未检查的效果填成“已复刻”，也不能仅因时长和分辨率正确就判定复刻质量合格。
