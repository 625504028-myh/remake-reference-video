# 帧级分析、去字与原视觉保留

先执行 `intake-workflow.md` 的全片双语提取和A/B输入选择。本页负责已授权范围内的文字替换；`motion-remake.md` 负责完整原视觉保留。两种输入方式都禁止按新稿重生成场景。

## 分析与对齐

以真实帧号为时间基准，区间左闭右开。`00:01:12`可能是帧时间码，不能未经核对解释为1.12秒。保留分数帧率；短片先每0.1秒抽样，再逐帧检查切点、闪帧、文字出入场与透视变化。提取覆盖全片，输出范围由A真实改动或B全文映射决定。

分别记录每组中文、英文、影层的源起止帧、稳定阅读段、退场和效果末帧。保存槽位ID、原文、新文、动作、分行、颜色、布局、运动曲线和映射依据。A按槽位ID读取在线表最新改稿，B从源第0帧匹配全部新稿；不能机械地一行等于一秒，不能跳过原片第一秒。

低置信度残片只进分析，不进成片。将能归属文字组的残片绑定同一新稿；无法确认时继续核对，禁止把“无法辨识”“转场局部”排到画面。原空屏和无字动作保持原样。

## 清除改动文字

先做若干“原帧／无字底片／换稿合成”抽检，再批量处理。阈值、坐标和遮罩全部来自当前参考片，不复用其他任务的固定区域。只清实际改动的语言及其附属文字效果，未改语言保持原样。

1. 在稳定帧和运动帧取前景/背景颜色，用颜色差、连通域、跟踪或识别结果制作文字遮罩。
2. 覆盖抗锯齿、描边、阴影、反射与拖尾；膨胀半径随分辨率及效果变化，不固定像素值。
3. 优先取真实无字时刻恢复原背景。时间中值要求多数样本看得到真实背景；全被字遮住的像素不能靠中值真实恢复。
4. 对需替换的英文和半透明影层单独处理；不能只清主标题，也不能把未改英文一起抹掉。
5. 匹配当前背景渐变与纹理，适量羽化，消除字形暗边及矩形补丁。
6. 遮罩外保留原画面；字下几何线可用相邻帧运动与已测量矢量几何恢复，不能生成新的线条或场景。

某些双色MG可用颜色分离，但蓝底白字、黑底彩字等须重新取样。`mask-color`是初始颜色遮罩，不是万能OCR；不能把所有同色装饰当文字删除。

### 常见边缘问题

- 英文字母很细，两端可能与圆点或线框相连，逐项区分文字和装饰。
- 不对整条字幕带做强开运算，避免抹断菱形斜线、细圆弧及光条；使用装饰保护遮罩。
- 同帧可能叠加两组出入场文字；按实际语言改动范围处理，不能只看稳定字幕框。
- 旋转文字远端会离开中央区域，巨字可覆盖全帧；遮罩应跟随完整运动包络。
- 明确删除某语言时清掉所有影层与拖尾；空白编辑单元格不代表删除。
- 实景移动背景先跟踪对齐，再基于真实相邻帧局部修复。无法恢复被遮住主体时报告具体差异，不用生成新场景冒充原画面。

### 清除工具

帧文件从`f_000001.png`开始，索引0对应文件000001；坐标为实际解码像素。先确认当前分析帧目录与输出源范围的映射，再运行工具。以下数值只是参数格式示例，必须按当前视频替换：

```bash
python3 "$SKILL_DIR/scripts/video_pipeline.py" mask-color --frames "$JOB/analysis/frames" --masks "$JOB/masks" --start 0 --end 60 --roi 40,400,640,500 --color F1EAC2 --tolerance 55 --grow 4
python3 "$SKILL_DIR/scripts/video_pipeline.py" clean --frames "$JOB/analysis/frames" --masks "$JOB/masks" --samples 0,72,114 --output "$JOB/clean_frames" --feather 1.5
```

`mask-color`可分区域叠加；`--protect`可传同名灰度保护遮罩目录，白色保护装饰。无遮罩帧原样复制，须确认意味着无需改字而非漏处理。查看遮罩和去字底片后才叠新字。

## 原字体与文字动效

默认识别和匹配原字体，检查字体是否实际可用及cmap覆盖。字体缺失时说明准确缺口并确认可接受替代，不默默输出缺字方框或换成不相关风格。公开版不包含私人字体；用户自行提供有权使用的字体。Noto 字体仅在与参考匹配或用户明确接受替代时使用，许可与来源见 assets/fonts/，不将其视为所有参考片的默认字体。

新句变长时保留数字/关键词层级，合理分行和适度调整字号；不要横向压扁或极小字硬塞。B全文不能因容量不足被自动删减，A改稿不能被自动改写。稳定阅读段保持可读，原本有意冲屏的转场依参考保留。

依新字数重算同一入场时段内的错峰，确保尾字完整出现；标点归所属短语。重复影层与主层绑定同一文本来源。中文、英文、装饰分别控制，保持各自原运动关系。采用适当超采样和仿射逆变换，避免因巨字冲屏生成异常巨大位图；未实现的透视、遮挡效果不能被静默忽略。

## 范围与音轨

A逐一导出真实改动区间；相邻或重叠的必要范围可保持原衔接合并，不连续范围分别输出。B从源第0帧导出至全文最后使用槽位的完整退场与效果结束；不导出下一旧标题或整条未用尾段。

共享过渡只按逐帧确认的最小依赖扩展，记录扩展理由；若无法兼顾效果完整和排除无关内容，说明具体边界冲突后等待取舍。不能擅自新增转场、循环、改速、停帧或延长。

默认保留对应源范围的原音轨并保持同步。工具中间产物若无音轨，最终必须按同一范围从原片复用或正确裁切音频；不能把中间静音文件当默认交付。用户本次要求静音、去配乐、保留人声/音效或新增配音时单独执行，并验证实际结果。

## 导出与验收

保持原方向、尺寸、帧率和镜头速度；编码兼容时使用H.264、yuv420p、faststart及合理质量。不得无明确要求改成竖版、480P、1080P或固定20秒。音轨、分辨率和帧率均须实际检查。

任务目录留存不可变提取基线、改稿来源、范围计划、视觉核对和验证记录。渲染采用唯一临时文件、目标锁及成功后原子替换；禁止两个进程写同名MP4。问题修复后只复查关联部分，不在旧任务未结束时重复覆盖。

逐项核对文字、镜头、场景、装饰和转场：除了获授权的文字内容及必要排版适配，其他原视觉全部保留。结构校验不能替代连续播放与逐帧对照。AE仅在真实执行预览/渲染后才能称完成；只有JSX时准确说明未执行。

## 能力边界

背景可分离、字清晰的MG较易精确换字。复杂实拍遮挡、极端模糊、三维文字、未知插件或缺失字体可能造成具体差异；先解决可完成部分并清楚说明限制，不能改变场景或省略动效后称为完全复刻。完整保留是目标，结论以实际对照证据为准。
