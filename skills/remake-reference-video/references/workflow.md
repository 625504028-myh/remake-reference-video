# 帧级制作与精确换字

先按 `SKILL.md` 确定制作模式、参考范围和文案策略。本页用于帧级分析、保留底片及文字合成；镜头重建同时执行 `motion-remake.md` 的五类运动拆解，不能仅执行本页就认定完成整片MG重建。

## 分析与对齐

以真实帧号为时间基准，帧区间左闭右开。00:01:12可能是帧时间码，不能未经核对理解为1.12秒。保留分数帧率。先粗分长视频，再密集检查文字变化；短片10fps抽样后仍要逐帧检查切点。

先将本次选定的参考区间映射到输出第0帧。每组记录源起止帧、输出起止帧、原中英文、用途、改稿、分行、颜色、布局范围、出入场曲线和映射依据。低置信度残片只进分析，不进画面。不要机械地一行等于一秒；数据按原片数据镜头的视觉层级匹配。连续重复快闪先判断新稿是否要每次不同。固定时长且允许部分使用时，保留可完整表达的连续前段并记录余稿；未允许时不得擅自删句。

## 清除旧字

先做5–10张“原帧／无字底片／换稿合成”抽检，再批量处理。所有阈值与坐标来自当前参考片。

1. 在多个稳定帧取前景/背景颜色，用颜色差、连通域或识别结果制作文字遮罩。
2. 膨胀覆盖抗锯齿、描边、阴影和拖尾；半径随分辨率与阴影变化，不固定10像素。
3. 选无字时刻恢复底图。中值要求多数样本看得到真实背景；全被字盖住的像素不能靠中值恢复。
4. 旧英文、半透明叠影需要单独阈值，不能只用主标题高亮遮罩。
5. 匹配当前底色/渐变、少量羽化，去掉字形暗边与矩形补丁。
6. 遮罩外保留原像素；被字遮住的几何线用相邻帧运动或已测量的矢量几何恢复，防止断线。

红底米金字实例可从G−B差与连通域分离，但蓝底白字、黑底彩字等必须重新取样；`mask-color`只是初始颜色遮罩，不是万能OCR。

### 常见边缘问题

- 英文细至2–4像素，容易残留；两端靠圆点时会与圆点连成同一对象。
- 不要整条字幕带做9×9开运算，它会抹断菱形斜线和细圆弧。先做装饰保护遮罩，只修确定的字母像素，必要时局限圆点足迹，并复查边缘。
- 相邻场景中英文可在同一帧交叠，遮罩需覆盖两者运动范围。
- 旋转字上下端会离开稳定字幕框，巨字可覆盖全帧；遮罩跟随运动包络，不能只清中央矩形。
- 不把转场残片的识别备注排到成片；能归属新句子的残片同步换字。
- 空屏照旧，不擅自补字。重复影层必须同时换稿。

实景移动底先跟踪对齐，再时序修复或使用确实可用的局部修复工具；检查一个完整镜头的连续性后再批量做。无法恢复被遮住的主体时具体说明，不称完美保留；生成式工具只在必要局部使用并检查漂移，不重新生成整片。

### 清除工具

原帧和遮罩按`f_000001.png`开始，索引0对应文件000001；坐标是解码原片像素。指定样本和区域由模型分析，不要求用户提供。

```bash
python3 "$SKILL_DIR/scripts/video_pipeline.py" mask-color --frames "$JOB/analysis/frames" --masks "$JOB/masks" --start 0 --end 60 --roi 40,400,640,500 --color F1EAC2 --tolerance 55 --grow 4
python3 "$SKILL_DIR/scripts/video_pipeline.py" clean --frames "$JOB/analysis/frames" --masks "$JOB/masks" --samples 0,72,114 --output "$JOB/clean_frames" --feather 1.5
```

可多次运行`mask-color`叠加不同颜色/区域。`--protect`传同名灰度保护遮罩目录，白色保护装饰。没遮罩的帧原样复制，须确认代表无须改字而非漏处理。先查看遮罩与无字底片，再渲染。

## 字体与动效

公开版默认使用 Noto Sans CJK SC Bold，首次运行自动从固定官方版本下载，许可见包内 SIL OFL 1.1。公开仓库不包含三极字体；用户提供有权使用的字体时优先采用，不改变其原授权。用fontTools检查cmap，禁止默默输出缺字方框。

新句变长时先保留数字/关键词层级，再分行和适度缩字；不要横向压扁或用极小字硬塞。允许按时长选稿时在语义单元之间取舍，不能从已选句子中任意删字改变含义。两行数字可大于说明，英文保持次级。稳定阅读段在安全区内，有意冲屏的转场可以超出画幅。

依据新字数重算同一入场时长里的错峰，确保尾字已显示；标点归所属短语。重复影层与主层绑定同一来源。文字纹理按2倍绘制后缩采样；仿射逆变换直接采样到画布，避免巨大转场创建几十倍尺寸的位图。

## 导出与验收

建议H.264、CRF16–20、yuv420p、faststart。低分辨率底片放大不代表细节恢复。默认不含音轨。

独立任务目录留存计划和验证记录，最终只交必要成片和可选工程。渲染用唯一临时文件、目标锁和成功后原子替换；禁止两个进程写同名MP4。发现问题修正相关阶段，不能在旧渲染未结束时对同一输出另开渲染。

镜头重建任务另保留镜头清单与实际实现证据，逐项核对文字、镜头、场景、装饰和转场；结构校验不替代画面对照。预渲染场景先验收无字动作，不能只检查最终文字。

同一计划驱动外部渲染和AE。AE文字使用PostScript字体名、原生文字层、中心锚点与关键帧。有AE真实预览才称验证；仅有JSX时说明未运行，仍以能播放的MP4为主交付。

## 适用范围

精确换字最适合背景可分离、字清晰、装饰为线框/圆环/粒子的MG快闪。镜头重建则须使用能实现对应动作与空间关系的工具，不受文字渲染器现有功能范围限制。复杂实拍遮挡、极端模糊、频繁三维遮挡和未知AE插件不能保证同样程度。单片成功不等于任意参考片都完美，也不能因为这些可能性跳过实际可完成的工作。
