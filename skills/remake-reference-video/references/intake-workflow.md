# 双语提取、改稿输入与选段

## 1. 全片提取是每次任务的第一步

完整分析参考全片后，建立按真实源帧排序的文字槽位。每个槽位包含可对应改稿的一组中文、英文及相关影层；同一镜头内不同时出现的文字不能因为位置接近而混成一条。记录各语言实际出现范围、稳定阅读段、入退场、效果尾部，以及共享转场依赖。相同文字的连续快闪可以共用文字来源，但保留每次出现的源范围。

向用户展示完整时间轴、原中文和原英文。全片提取既服务A，也服务B；即使用户已给完整脚本，也不能略过提取直接套文字。OCR不确定处明确标记并核对真实帧，不用推测内容填满基线。

保存不可变基线，至少包含：

| 字段 | 用途 |
|---|---|
| 稳定槽位ID | 将改稿对应回原片，不依赖表格行号 |
| 原起止时间与源帧区间 | 保留真实时间依据；内部帧区间左闭右开 |
| 原中文、原英文 | 保留逐语言原文，分别比较改动 |
| 文字完整结束、效果结束 | 确定实际交付边界，不截断退场或拖尾 |
| 转场依赖范围及证据 | 只有确实不可分离的运动才允许最小扩展 |
| 原字体、样式、音轨与媒体信息 | 避免沿用其他任务默认设置 |

时间码含帧数时附帧率，不能把 `00:01:12` 未经判断解释为1.12秒。保留源帧号与输出局部帧号的映射。

## 2. 选择A或B

尚无明确选择时，用简短问题询问：“你选A：在在线表格逐段修改，还是B：直接发完整脚本？”同时说明A只导出改动片段，B从原片开头匹配全文并在用完处结束。

用户已明确选A、已在现有表格改好，或明确要求直接套用所给全文时，按其选择继续，不重复确认。没有回答时不擅自转B。仅提取阶段可继续核对时间轴，依赖选择的制作等待选择确定。

## 3. A：真正可编辑的在线表格

优先使用当前已连接且支持写入的在线表格服务，例如Google Sheets；也可使用明确具有持久保存和重新读取能力的在线表格应用。检查用户能打开并编辑，给出真实链接；保护原文与时间信息，按已有授权设置访问权限，不自行公开用户素材或脚本。

Markdown表格、截图、静态HTML、本地XLSX不等于在线表格。在线写入能力不可用时说明具体限制，可提供可编辑文件作为待用户接受的替代，或请求所需连接；不能谎称已提供在线编辑，也不能静默改走B。

建议列：

| 固定列 | 用户编辑列 |
|---|---|
| 槽位ID、原起止时间、原中文、原英文 | 修改后中文、中文动作、修改后英文、英文动作 |

固定列在在线服务支持时设为保护列；同时保存独立不可变基线。编辑列可默认留空，动作默认“保留”。说明“填入新文字即可替换；不改的留空；删字请选删除”。如服务不支持动作下拉，接受明确的文字删除指令并转换为结构化动作，不把普通空白当删除。

### 按每种语言判定真实改动

| 用户输入 | 判定 |
|---|---|
| 动作未改或保留，新文字为空 | 保留原文 |
| 新文字与原文不同，未明确删除 | 自动判为替换；不要求再填写动作 |
| 新文字与原文相同 | 无变化，不进入导出清单 |
| 明确删除 | 删除该语言的全部对应文字层、影层和拖尾 |
| 中文改了、英文空白 | 只换中文，原英文保留；不自动翻译 |
| 英文改了、中文空白 | 只换英文，原中文保留 |
| 原文已经为空，又明确删除 | 无实际变化 |

动作与文字真正冲突、文字不明或重要数字有歧义时，只询问该冲突。不能把单元格被清空、整行被删除、行号变化、缺失槽位ID或读取失败推断为删除；缺失/重复ID先核对原表。保留有意义的标点、数字、空格和换行，不用宽松文本归一化吞掉用户排版变化。

收到用户“已改好”后，通过服务重新读取当前值和可用版本信息，与不可变基线逐语言比较，不能使用助手记忆或首次创建表格时的旧内容。若用户制作过程中又改表，在最终采用前重新核对相关行；发现更新就以最新明确改稿为准。

### 只导出实际改变的片段

根据真正发生替换或删除的槽位计算源范围，覆盖该文字入场、稳定段、退场、影层及其必需过渡。其他槽位只作为原画面保留，不进入改动集合。

- 不连续源区间分别导出，不用新转场拼成合集，也不把中间未修改镜头一起输出。
- 直接相邻、且原连接可原样保留的区间可以合并；重叠依赖范围先去重合并。
- 仅当有逐帧证据表明文字效果依赖边界外的共享动作时，扩展到最小必需范围；记录原范围、扩展范围与原因。
- 扩展不能带入完整无关标题或额外镜头。若过渡不能分离，明确指出边界冲突并询问，不改动原动画来掩盖冲突。
- 没有真实变化时不生成“修改版”；告知未检测到文字变更。

每个文件标注原片时间范围，便于用户回填或复用。音频按同一源范围裁切并保持同步，除非用户本次要求其他处理。

## 4. B：完整脚本从开头匹配

将完整新稿按原顺序拆成完整语义单元，保留所有字句、数字、单位、条件及用户提供的双语对应。允许为了排版换行或在语义边界拆分，不允许为了适配擅自删句、缩写、增加口号或改写含义。

从参考第0帧开始，按原槽位顺序适配全文。原片开头的无字动画、空屏与镜头运动仍保留；“第一秒开始”不是把起点设成1.0秒。原本属于同一文字组的影层和快闪重复使用同一替换来源，不额外消耗或复制新稿。

逐槽位检查新文字在原稳定阅读段内是否可读。长句可在相邻原槽位中按语义拆分，但不得跳过前文去挑后面的重点，也不能通过缩小成不可读字或改变原节奏强塞全文。

输出 `[源第0帧, 最后使用槽位的完整结束帧)`：包括最后新文字的退出、拖尾和必需效果；排除后续未使用的旧标题与原片剩余尾段。最后镜头无需额外尾卡、延长停帧或新增收尾转场。若下一旧标题提前进入并与尾效不可分，说明具体冲突，不能暗中清空旧标题或截掉尾效假装合格。

超过参考容量时，保留已完成的提取与映射，说明还有哪些新稿无处放入，并询问用户处理选择。未获得新指令前，不自动截断脚本、重复镜头、延长原片、调整速度或默认只做20秒。

用户若提供中英文则按其对应采用；明确“英文统一…”或“删除英文”时按范围执行。未给英文修改要求时保留原英文，明确要求自动翻译时才生成对应英文并记录。

## 5. 转成可验证计划

按 `text-replacement.md` 中 `text_replacement.py` 的输入格式，将不可变提取基线、A当前编辑值或B全文映射、源区间、出场结束及视觉保留策略写入校验输入。每个渲染计划同时关联选段检查和五类动效清单；不得为了通过校验而把真实未完成项标为完成。选段校验只核对内容与范围约束，不替代逐帧视觉对比，也不证明复杂文字效果完全一致。

输出计划保留原画面、原镜头和原音频处理依据；每个语言变更须能追溯到用户编辑或明确指令。A的多个文件与B的单个前缀分别验收，不能用全片渲染掩盖选段错误。
