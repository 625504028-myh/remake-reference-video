# MotionForge AI｜AI 自动生成 MG 动画视频

## 当前工作约定

以参考原视频为唯一视觉依据，**只替换文字，保留全部原动效、动画、场景、元素、镜头运动、转场、配色、材质与风格**。新稿主题变化不授权更换场景或道具。以完整复现为制作目标，但不能把仅有MP4时未验证的结果宣称为源工程级或逐像素一致。

每次制作必须先提取参考全片的时间轴与全部中文、英文，再进入以下一种输入方式：

| 方式 | 用户如何提供新稿 | 输出范围 |
|---|---|---|
| **A：在线表格逐段修改** | 在真正可在线编辑的表格中修改某些中文或英文 | 只输出实际修改的片段；不连续的片段分开交付 |
| **B：提供完整脚本** | 直接发送完整新稿，无须填表或标时间码 | 从参考第0帧开始，按顺序使用全部新稿，输出至最后已使用槽位的退场及效果尾部结束 |

用户已明确选择方式、已在表格修改，或已明确要求直接使用所给全文时，不重复询问选择；但仍先提取全片双语基线。尚未选定时，完成提取后给出A/B的简短选择，等待用户决定，不擅自采用B。仅要求更新本Skill时，不启动无关的视频或表格制作。

## 默认设置与优先级

优先级：本次明确要求 ＞ 本次提供的项目、字体与品牌规范 ＞ 参考原片。旧任务的静音、配音、字体、竖版、分辨率或时长要求不自动带入新任务。

| 项目 | 默认处理 |
|---|---|
| 画幅、尺寸、方向 | 与参考一致，不默认改竖版、不裁切、不拉伸 |
| 帧率、镜头速度 | 与参考一致，保留分数帧率和原节奏，不默认加速、循环、重复或延长 |
| 字体与文字样式 | 尽量识别并匹配参考的字体、字重、纹理、描边和层级；无法准确匹配时说明具体缺口，不偷偷换成另一种风格 |
| 音频 | 按导出范围同步保留原音轨；仅在本次要求静音、去配乐、保留音效或新增配音时执行对应处理 |
| 交付 | 可播放的MP4；兼容性允许时使用H.264、yuv420p、faststart，保留可用源工程 |
| 时长 | A由实际改动片段决定；B由完整新稿最后占用槽位决定，不默认20秒，也不保留无用尾段 |

保留原素材，不覆盖原片。低清素材放大不等于细节恢复。公开版不包含私人字体。优先使用实际匹配参考或用户明确提供的授权字体；缺失时说明差异并确认替代。包内可获取 SIL OFL 1.1 授权的 Noto 字体，但不得在只换字任务中未经确认自动替换参考字体。

## 1. 能力检查与完整提取

先读 `references/intake-workflow.md`，再读 `references/workflow.md` 与 `references/motion-remake.md`。生成选段任务时读 `references/text-replacement.md`，编排合成计划时读 `references/plan-format.md`。每个输出都按 `references/shot-contract.md` 记录五类动效与保留依据，不能省略。

1. 检查完整参考视频的方向、尺寸、帧数、帧率、时长、音轨及可用源工程。缺素材时先定位会话或可访问文件，只询问确实缺失的必要信息。
2. 检查FFmpeg/ffprobe和所需Python依赖。用户指定AE或复杂文字效果需要AE时读取可用after-effects指南，确认真正可运行的AE/aerender或连接；仅有指南不等于AE已安装。
3. 有可编辑AE工程且可运行时优先替换原文字层，保留原属性、表达式、效果及音频。仅有MP4时保留底片并进行局部去字与文字动效重建；不得因此重新设计或生成场景。
4. 完整查看全片，短快闪先每0.1秒抽帧，切点、闪帧、透视、旋转、巨字和遮挡再逐帧检查。OCR辅助识别，不能用音频转写或少量缩略图代替画面双语提取。
5. 记录所有中文、英文、数字、重复影层、进出场残片及其真实帧区间。看不清时标明不确定处并继续核对，不编造原文，不把分析备注放进成片。
6. 向用户呈现完整时间轴提取结果，保存不可变原文基线；然后根据已知选择进入A或B。全片提取不等于最后必须导出全片。

`SKILL_DIR`和`JOB`分别为本Skill目录与任务目录，使用真实绝对路径。首次提取面向完整参考，不预先裁成20秒或仅抽取预计修改区域：

```bash
python3 "$SKILL_DIR/scripts/video_pipeline.py" prepare --video "$JOB/reference.mp4" --job "$JOB/analysis" --step 0.1
```

## 2. 接收改稿并确定输出

### A：在线表格逐段修改

按 `references/intake-workflow.md` 创建真正可在线编辑且用户具有编辑权限的表格，提供链接并等待改稿完成。保护原文、槽位ID和源帧信息；编辑列分别提供新中文、新英文及保留/替换/删除动作。不能把Markdown表、静态网页或本地XLSX冒充在线编辑表格。

收到“已改好”后重新读取在线表格当前值，与不可变基线按槽位ID逐语言比较。填写新文字即视为替换；空白默认保留，明确“删除”才删。只改中文时保留英文，反之亦然；不得把空白英文自动翻译，也不能因行被移动或删除而猜测文字删除意图。

生成真实改动清单，仅处理改动槽位对应的片段。非连续范围分别输出MP4；直接相邻且能保留原连接的范围可合并，不增加转场，不把中间未修改镜头或整片顺带输出。共享过渡只按已核实的最小依赖范围扩展，不能借此带入完整无关内容。没有实际变化时说明未检测到改动，不渲染原片冒充修改版。

### B：提供完整脚本

从参考第0帧开始，按新稿原顺序映射全部内容到原文字槽位。“从第一秒开始”表示从开头开始，不跳过0–1秒。保持原镜头和槽位节奏；语义完整地拆分短句、必要分行，保留数字、单位、条件和中英文对应关系，不擅自缩写、补数据或增加口号。

导出参考前缀，结束点取最后使用槽位的文字退场、拖尾及必需效果结束位置；不追加下一条未替换的旧标题，不顺带导出原片剩余尾段。前缀中的原始空屏、开场运动和镜头间停顿保持原样，不能作为任意补字空间。

新稿超过参考可读容量时，明确指出剩余内容及冲突，询问用户如何处理；不得自动截稿、只取前20秒、循环镜头、加速、拉长或极小字硬塞。最后文字尾效与下一旧标题不可分离时同样说明真实边界冲突，不能假称同时满足两个要求。

两种方式均按用户本次明确给出的中英文、统一英文或删除指令执行。未提供某语言的替换要求时保留该语言原文；只有明确要求自动配英文时才翻译并记录，不杜撰品牌官方英文名。具体输入、基线、动作和范围规则以 `references/intake-workflow.md` 为准。

## 3. 保留原画面并替换文字

按 `references/motion-remake.md` 分别核对文字、镜头运动、场景动画、装饰元素、转场五项。后四项保持原样；第一项仅替换内容并按新字数适配同一套动画，不能把复杂效果降级成普通缩放或淡入淡出。

清除需替换的主字、对应旧英文、影层、描边、模糊拖尾及入退场残留；未选语言不得误清。用真实相邻无字帧、跟踪对齐或有依据的局部修复恢复被文字遮盖的原背景。建立装饰保护遮罩，保留同色线框、圆环、光条和粒子；不得用大块色块盖字或生成新场景替代原底片。

按参考实测轨迹、相位、节拍、遮挡和材质重建文字。所有重复影层与主层绑定同一新稿；中文、英文及装饰独立控制。按新字数重算同一入场时段内的错峰，稳定阅读段不裁字，巨字冲屏保留原意图。不能恢复的遮挡区域、未知插件或字体差异须明确说明，不凭想象宣称完全相同。

包内脚本只具有已实现的能力。复杂透视或三维文字效果要用实际可用的AE、跟踪或合成能力完成；不能为迁就文字渲染器而删除参考效果。没有实际可执行环境时说明缺失，不把代码、JSX或提示词称为成片。

将选段、新旧文字对应关系、保护区域、原音轨处理及实际关键帧写入渲染计划，关联 `replacement_contract` 和 `mode: text-replace` 的 `motion_manifest`，并按输入清单校验。表格模式可为每个不连续输出范围生成独立计划；全文模式只生成所需前缀。结构检查不等于视觉验收。

## 4. 验收与交付

完整播放每个实际输出文件，并与对应原片范围逐镜对照。检查全部稳定段和每个切点前后至少3帧，修复问题后复查相关镜头。

- **文字**：仅发生获授权的修改；中文、英文、标点、数字、单位、影层和转场层完整正确；无旧字残留、无误译、无未改语言被清空。
- **范围**：A只有真实修改片段及必要过渡依赖；B从第0帧起且全文全部使用，停在最后文字及效果完成处，无无用原片尾段或下一旧标题。
- **原视觉**：镜头、场景、元素、配色、材质、光影、动画及全部转场原样保留；没有主题替换画面、丢失效果、断线、补丁或新增动作。
- **可读性**：新字在原节奏内可读，尾字完整；不靠改变速度、时长或极小字号解决容量冲突。
- **技术与声音**：核对尺寸、方向、帧率、帧数、源范围、音轨及同步；无明确要求时不静音、不增加配音、不换字体或改画幅。

```bash
python3 "$SKILL_DIR/scripts/video_pipeline.py" verify --video "$JOB/final.mp4" --plan "$JOB/plan.json" --report "$JOB/validation.json"
```

交付可播放/下载的MP4，按平台要求持久保存；A逐个标明对应原时间段，B说明使用全部新稿及实际时长。只在确有差异时具体说明受影响的镜头或效果。需要时附可用工程，但不能仅交代码或静态图。若表格仍待用户编辑、输入选择未确定或容量冲突未解决，保留已完成的提取结果并停在该步骤，不冒充已完成视频。
